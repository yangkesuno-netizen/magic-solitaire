## 技术方案

### 文件结构
```
src/
  - UIScene.ts         # UI 管理场景
  - GameUI.ts          # UI 组件（分数、按钮）
  - VictoryScene.ts    # 胜利界面
  - style.css          # 更新样式
```

### Phaser 组件
- **Text**: 分数、剩余牌数显示
- **Rectangle**: 按钮背景
- **Container**: UI 组件分组
- **Tween**: 动画效果

### 样式指南
- **主色调**: #1a1a2e (背景), #0075ca (按钮), #a2eeef (文字)
- **字体**: Arial, 无衬线
- **按钮**: 圆角矩形，悬停效果
