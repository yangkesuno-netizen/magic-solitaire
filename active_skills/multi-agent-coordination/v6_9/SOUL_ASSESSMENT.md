## 灵魂拷问清单

在评估前，先进行灵魂拷问：

1. **这是我能做的最好的吗？** → 必须诚实回答
2. **如果全世界都看到，我自豪吗？** → 每个细节都要经得起审视
3. **我是否为了省事而妥协了质量？** → 不能有任何妥协
4. **这能经得起时间的考验吗？** → 不是短期可用，而是长期优秀
5. **我是否真正理解了问题，还是在应付？** → 深度理解，不是表面功夫
