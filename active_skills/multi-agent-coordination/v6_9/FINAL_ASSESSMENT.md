```python
graph = CausalGraph()
graph.add_edge("A", "B", 1.0)

# 分叉结构: A<-B->C, 给定B阻断

graph2.add_edge("B", "C", 1.0)
assert graph2.is_d_separated("A", "C", {"B"}) == True ✅

# 对撞结构: A->B<-C, 不给定B阻断
graph3 = CausalGraph()
graph3.add_edge("A", "B", 1.0)
graph3.add_edge("C", "B", 1.0)
assert graph3.is_d_separated("A", "C", set()) == True ✅
```

**验证结果**: 三种结构全部正确，**真正实现**。
