## 学习记录

### 安全审查流程
- 使用 skill-vetter 进行代码审查
- 检查要点: 来源、作者、下载量、更新时间、危险代码模式、权限需求
- 风险分级: 🟢 LOW 🟡 MEDIUM 🔴 HIGH ⛔ CRITICAL

### Windows 命令差异
- 使用 `dir` 替代 `ls`
- 使用 `cd` 替代 `pwd`
- 使用 `xcopy /E /I` 替代 `cp -r`
- 使用 `del` 替代 `rm`
- 使用 `rmdir /S /Q` 替代 `rm -rf`
- 使用 `powershell -Command "Expand-Archive"` 解压 zip

### Skill 安装流程
1. 浏览器打开 skill 页面获取信息
2. curl 下载 zip 包
3. PowerShell 解压
4. 审查所有文件 (SKILL.md, _meta.json, 脚本等)
5. 生成 vetting report
6. xcopy 安装到 active_skills/
7. 清理临时文件
