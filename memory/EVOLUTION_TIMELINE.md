```
HIGH (61-85分): 系统命令/权限操作 → 需审批
CRITICAL (86-100分): 代码执行/危险操作 → 需审批
```

**质量评分**: 9.9/10

### 🛡️ v5.0 - Safety First Edition (2026-03-15)

**事故触发**: 3D象棋项目源代码批量损坏事故

**核心教训**
- 缺乏安全网机制 (无备份、无预检查、无编码保护)
- 环境感知不足 (require混入浏览器代码)
- 增量验证缺失 (60+类型错误累积到最后)
- 回滚优先思维缺失 (试图修复而非恢复)

**新增核心模块**

| 模块 | 功能 |
|------|------|
| BackupManager | 强制Git提交备份、文件级备份、一键恢复 |
| EnvironmentDetector | 浏览器vs Node.js自动识别、模块系统检测 |
| ContinuousValidator | 即时类型检查、编码验证、构建验证、失败自动回滚 |
| CircuitBreaker | 失败阈值控制、自动停止防止扩大损失 |
| SafetyContext | 操作上下文管理、自动备份触发、失败自动恢复 |

**新增核心规矩 #4-6**
- #4: 修改前必备份
- #5: 持续验证
- #6: 环境感知

**质量评分**: 9.0/10
