# Self-Check Skill v1.0

> **强制执行：每次行动前必须完成**

## 快速检查（30秒）

### 检查1：任务理解
```
□ 我是否清楚知道要做什么？
□ 我是否知道"完成"的标准是什么？
□ 我是否有所有需要的信息？
```
**如果任一否 → 启动 Phase 1: 定义问题**

---

### 检查2：方法论应用
```
□ 这是一个需要解决的问题吗？（vs 简单的执行）
□ 如果是问题，我是否用了四阶段法？
□ 我是否跳过了任何阶段？
```
**如果跳过了 → 暂停，回到跳过的阶段**

---

### 检查3：质量标准
```
□ 这是我能做的最好的吗？
□ 我是否在追求9.5+/10？
□ 我是否为了省事而妥协？
```
**如果任一否 → 重新思考方案**

---

## 完整检查（2分钟）- 复杂任务

### Phase 1: 定义问题确认
```
□ 问题陈述是否一句话能说清？
□ 是否有截图/日志等客观证据？
□ 是否知道"正确"应该是什么样？
```

### Phase 2: 根因分析确认
```
□ 是否用了5 Whys找根因？
□ 是否区分了表面原因和根本原因？
□ 是否有对比分析（当前vs期望）？
```

### Phase 3: 设计方案确认
```
□ 是否画了草图/写了伪代码？
□ 是否对比了多个方案？
□ 选择依据是否明确（正确性>性能>简洁）？
```

### Phase 4: 验证计划确认
```
□ 验证清单是否已准备？
□ 如何验证"正确"？
□ 用户如何验收？
```

---

## 执行决策树

```
开始任务
  │
  ├─ 是简单执行？（如：读取文件）→ 直接执行
  │
  └─ 是问题解决？（如：修复bug）→ 启动四阶段法
       │
       ├─ Phase 1 → 定义问题
       ├─ Phase 2 → 根因分析
       ├─ Phase 3 → 设计方案
       └─ Phase 4 → 执行+验证
```

---

## 复盘检查（任务完成后）

```
□ 我是否用了方法论？（诚实回答）
□ 哪里可以改进？
□ 是否需要更新文档？
□ 是否记录了教训？
```
