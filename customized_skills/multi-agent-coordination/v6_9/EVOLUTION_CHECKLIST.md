# 进化验证清单

## 自我进化技能验证

### 遇到测试失败时
- [ ] 第一反应是检查系统代码
- [ ] 第二反应是修复系统（不是测试）
- [ ] 记录为什么之前想简化测试

### 遇到用户指出错误时
- [ ] 立即承认（不辩解）
- [ ] 分析根本原因
- [ ] 提出具体改进措施

## 规划技能验证

### 新任务规划时
- [ ] 基于AI能力估算（不是人类节奏）
- [ ] 给出最短时间（不是"安全"时间）
- [ ] 如果提前完成，立即调整计划

### 计划执行时
- [ ] 实际用时 vs 计划用时对比
- [ ] 如果差距>50%，分析原因
- [ ] 更新计划，不维护错误计划
